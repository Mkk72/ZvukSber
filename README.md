# ZvukSber — настольный плеер Звука (zvuk.com)

Обёртка официального веб-плеера `zvuk.com`: сайт живёт в своём окне, а управлять им можно
из полосы 35 px в углу экрана, из трея и мультимедийными клавишами. Никакого обхода DRM
и никакого реверс-API: играет тот же плеер, что в браузере, подписка остаётся ваша.

## Что уже работает

- Окно с сайтом (вход по Сбер ID, сессия сохраняется в профиле).
- **Полоса 35 px** — обложка, «Трек — Артист», дизлайк, ⏮, ⏸/▶, ⏭, ♥, время, прогресс линией 2 px.
- **Широкая плашка ~420×110** — та же плашка плюс перемешать, повтор, очередь (переключение в меню).
- **Меню на плашке** (кнопка `☰`): что играет, play/pause, prev/next, лайк, дизлайк, перемешать,
  повтор, очередь, **«Поток ▸»**, «Скрыть окно», «Поверх всех окон», «Вид», «Запускать с Windows»,
  «Выход», «Настройки…», «Папка профиля». Меню раскрывается вверх, полоса остаётся на месте.
- **Выбор потока**: «Поток ▸» открывает список — «Мой поток» (по умолчанию, первый),
  настроения и жанры с главной сайта: Утро, Спорт, Медитация, Поп, Хип-хоп, Рок, Веселое,
  Легкая, а также карточки из «Недавнего». Список не зашит: он читается со страницы при
  каждом открытии, поэтому новые подборки появятся сами.
- Трей: то же меню плюс подсказка «Артист — Трек».
- Мультимедиа-клавиши клавиатуры и горячие клавиши (см. ниже).
- Закрытие окна — в трей, приложение остаётся и продолжает играть.
- Автозапуск с Windows (пункт меню, ставит ярлык в автозагрузку).

## Запуск

Нужен Node.js 20+ и Windows 10/11.

```powershell
npm install
npm run build
npm start
```

`npm start` запускает Electron с флагом `--no-sandbox`. Почему он тут: на этой машине
Chromium-песочница Electron не поднимается (падение до выполнения кода, проверено на
Electron 40 и 45). Причина не в профиле, не в GPU и не в ASLR. Подробности —
в [NOTES-spike.md](NOTES-spike.md). На другой машине флаг можно убрать в `package.json`.

## Вход

Первый запуск: в окне приложения нажмите «Войти» и пройдите Сбер ID как в браузере.
Сессия лежит в `%APPDATA%\ZvukSber\Partitions\zvuk\Network\Cookies` и переживает
перезапуск и обновление сборки. Разлогиниться — там же: «Выйти» на сайте или удалить
каталог `%APPDATA%\ZvukSber`.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Мультимедиа play/pause, next, prev | пауза и переключение треков |
| `Ctrl+Alt+Space` | пауза / воспроизвести |
| `Ctrl+Alt+←` / `Ctrl+Alt+→` | предыдущий / следующий трек |
| `Ctrl+Alt+L` | лайк |
| `Ctrl+Alt+M` | сменить форму: полоса ↔ широкая плашка |
| `Ctrl+Alt+Z` | показать / скрыть окно с сайтом |

## Если что-то не так

- **Сайт пишет «Сайт не работает с включённым VPN».** Zvuk отдаёт HTTP 418 на прокси
  и VPN-адреса. Приложение по умолчанию ходит напрямую (`proxyDirect: true`
  в `%APPDATA%\ZvukSber\settings.json`).
- **Полоса показывает «ничего не играет».** Пока трек не запущен в окне с сайтом,
  управлять нечем: плеер создаётся при старте воспроизведения.
- **Кнопки в полосе не реагируют.** Сайт мог обновиться. Откройте окно с сайтом и
  запустите трек вручную; диагностика пишется в `_diag/state.json` (какая стратегия
  сработала, какие обработчики зарегистрированы).

## Настройки

`%APPDATA%\ZvukSber\settings.json`:

| Ключ | Смысл |
|---|---|
| `noSandbox` | запускать Chromium без песочницы (нужно на этой машине) |
| `proxyDirect` | обходить системный прокси (иначе сайт блокирует) |
| `alwaysOnTop` | полоса поверх всех окон |
| `layout` | `bar` (35 px) или `wide` (110 px) |
| `barWidth`, `wideWidth` | ширина каждой формы, запоминается при растягивании |
| `closeToTray` | закрытие окна прячет в трей |
| `mediaKeys` | регистрировать мультимедиа-клавиши |
| `startHidden` | стартовать без окна с сайтом |

## Установщик

```powershell
npm run dist        # NSIS-установщик в release\
npm run dist:dir    # неподписанная сборка в release\win-unpacked (быстрее)
```

`release\win-unpacked\ZvukSber.exe` уже проверен: запускается, играет, полоса и трей на месте.
⚠ Установщик `release\ZvukSber Setup 0.1.0.exe` собирается, но **тихая установка на этой машине
не проверена** — запуск `/S` повис, разбираться не стал, чтобы не мешать работе.
Ярлык установщик создаёт сам, с `--no-sandbox` (см. `installer.nsh`) — без аргумента
упакованное приложение падает так же, как из исходников.

## Устройство

```
src/core/    — логика без Electron: состояние, команды, меню трея (vitest)
src/main/    — Electron: окна, трей, мост к странице сайта, презентер
src/preload/ — мост в мини-плеер
app/         — вёрстка полосы (HTML/CSS/JS без сборки) и иконки
test/        — тесты ядра и презентера (фейковые виды, без окон)
```

Управление сайтом — три стратегии с автоматическим откатом:

1. обработчики `navigator.mediaSession` самого сайта (перехват ставится CDP-скриптом до
   скриптов страницы);
2. клик по кнопке сайта по `aria-label` (`Нравится`, `Перемешать`, `Повтор` и т. п.);
3. синтетические клавиши.

Прогресс и метаданные берутся из состояния плеера сайта, а не из своего таймера.
